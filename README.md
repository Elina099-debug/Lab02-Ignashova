## ПР2. Ответы на контрольные вопросы

**1.** decimal считает точно, а double с маленькой погрешностью: 0.1 + 0.2 даёт 0,30000000000000004. Для денег берут decimal.

**2.** Ошибки не будет, число пойдёт по кругу: byte b = 255; b++; даст 0. Чтобы получить OverflowException, нужен checked.

**3.** В Python тип может меняться на ходу, а в C# var определяет тип один раз при компиляции. Поэтому его сразу надо инициализировать.

**4.** string.

**5.** Parse на буквах падает с FormatException, TryParse просто возвращает false.

**6.** Не удалось превратить строку в число. В out будет 0.

**7.** Когда число вводит пользователь: можно проверить результат и попросить ввести заново, а не вылететь с ошибкой.
